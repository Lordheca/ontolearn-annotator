feat(annotations): point image consumers at the authenticated /api/files/[id] proxy (Phase 1, Step 3)

Three places still linked straight to DataFile.filePath — the raw,
no-longer-public path Step 1 moved outside public/. Point them at the
/api/files/[id] proxy from Step 2 instead, so they go through the same
ABAC check as every other read path.

- src/app/projects/[slug]/annotations/[dataFileId]/page.tsx:
  WorkflowAnnotator's imageUrl is now `/api/files/${dataFile.id}`
  instead of dataFile.filePath.
- src/app/_components/annotations/annotations-table-client.tsx: the
  read-only AoiPreviewModal opened from "View" now takes
  `/api/files/${df.id}` instead of df.filePath.
- src/app/_components/data/columns.tsx: the Data table's download link
  now points at `/api/files/${row.original.id}` instead of
  row.original.filePath; updated the stale comment referencing the old
  /datasets/{projectId}/{content} 404.

None of these three send an Authorization header — the browser's
session cookie carries the request, so /api/files/[id] falls back to
checkPermission (not checkPermissionForApiKey), same as any other
signed-in page.

Verified 2026-09-14 against the local stack: annotation viewer loads
the image for an existing MANUAL-destination DataFile; the Annotations
table's View modal shows the correct image for a completed annotation;
the Data table's download link downloads the file.
